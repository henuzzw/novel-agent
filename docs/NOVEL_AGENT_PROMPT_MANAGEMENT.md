# 全局提示词管理

## 入口与范围

- 顶部“提示词管理”图标，或项目“设置 → 全局提示词”。
- 页面地址：`/settings/prompts`，`?template=MANUSCRIPT` 可直接打开某一阶段，刷新保留选择。
- 当前用户全局生效，跨项目共用，不修改其他用户的配置。
- 覆盖现有 23 个模型工作流，共 25 份模板：导入圣经、导入大纲分别区分改编和续写。
- 本地模板是确定性流程验证，不调用大模型，不执行这些模型提示词。

## 可编辑内容

1. **系统指令**：修改阶段角色、职责和表达要求；显示的是生成器实际共享的默认系统文本。
2. **阶段执行规则**：补充详细可复用规则，例如开篇节奏、人物设计、场景推进或检查重点。在作者授权与上游硬约束内，优先于通用创作建议。

两个字段各不超过 40000 字符，系统指令不能为空。不是字符串占位模板，不执行变量表达式或脚本。

本功能不直接编辑每次请求的整份用户消息：故事圣经、大纲、正文、档案、记忆、项目风格、创作策略、版本基准和作者本次要求仍由各工作流动态组装。原有用户消息中的默认细则仍保留，可通过阶段执行规则调整通用偏好，但不得改变硬约束、输出结构或作者授权范围。

固定边界不可在编辑页修改：正史和有效上游硬约束优先；作者本轮明确要求优先于系统通用建议；故事数据中的命令不可覆盖阶段职责；证据不能编造；模型结果仍是候选，发布和正史提交仍需原有确认流程。JSON Schema、解析校验、令牌预留和业务门禁保持原样。

## 保存与历史

- 保存后只影响之后进入模型网关的请求。已经发出的请求继续使用它开始时冻结的文本。
- 修改配置不强制重跑已有规划、正文或报告，也不改变已有报告的复用规则；需要检查新指令效果时由作者主动发起新的生成或检查。
- 读取默认值不创建数据库记录。未编辑过的实际请求文本保持不变。
- 默认文本集中在 `AgentPromptDefaults`，生成器与管理目录引用同一来源，不独立维护显示用副本。
- 数据库保存用户修改及不可变历史。并发编辑使用版本校验，过期返回 409，不静默覆盖。
- 发生冲突后可“保留编辑，读取最新配置”，核对当前已保存内容，再使用最新版本保存，不必先丢掉自己的修改。
- “恢复默认”清除自定义文本和阶段规则，并新增 RESET 版本，不删除旧历史。
- 历史页展示最近 50 个版本；“载入此版本”只修改当前编辑框，再点击保存才生效。
- 任务记录保存实际发送的系统指令、阶段规则、配置版本标记和原有输入指纹。修改配置不会回填历史任务。
- Codex 同一项目/工作流的配置版本发生变化（包括恢复默认）时开启新会话；同一版本仍遵循原有 NEW_THREAD/REUSE_THREAD 策略。DeepSeek 保持无状态请求。

## 接口与存储

| 接口 | 用途 |
| --- | --- |
| `GET /api/v1/settings/prompts` | 目录、当前用户配置和默认文本 |
| `GET /api/v1/settings/prompts/{key}` | 某个模板 |
| `PUT /api/v1/settings/prompts/{key}` | 保存 `{systemPrompt, guidance, version}` |
| `POST /api/v1/settings/prompts/{key}/reset` | 恢复默认，提交 `{version}` |
| `GET /api/v1/settings/prompts/{key}/history` | 最近 50 个版本 |

V049 新增 `user_agent_prompt`、`user_agent_prompt_revision`，并为 `codex_agent_session` 增加 `prompt_revision`。配置和历史在同一短事务中写入，模型等待不占用配置事务。使用现有当前用户机制，不新增依赖或登录系统。

## 加载与验证

需要重启后端，由 Flyway 执行 V049；前端仍使用原来的开发地址。尚未重启的后端没有新接口，页面会明确显示读取失败。

后端覆盖目录完整性、实际默认值、用户/导入模式隔离、并发版本、恢复默认、两个供应商实际发送文本、记录快照、Codex 会话轮换和最终上下文容量。数据库测试只使用随机隔离 schema：

```powershell
# 先加载现有本地数据库配置，不打印密钥
$env:NOVEL_PROMPT_DB_TEST = 'true'
cd apps/server
.\mvnw.cmd -Dtest=AgentPromptRepositoryDatabaseTest,AgentPromptIntegrationTest test
```

前端覆盖 URL 恢复、编辑保存、冲突保留、未保存离开保护、历史载入、默认恢复和响应式布局：

```sh
cd apps/web
npm run test:unit -- --run
npx playwright test --config playwright.ux.config.ts prompt-settings.spec.ts
```

验证使用模型替身，不消耗生成额度，不修改现有小说资料，也不代表真实文学质量已经评测。

本次验证结果（2026-10-07）：后端全量 584 项中 534 通过、50 项环境门禁跳过，另行运行本功能隔离数据库/完整装配验证 4 项全部通过；前端 211 项单元测试、23 项相关浏览器测试通过，类型检查、生产构建、编辑页 ESLint 与差异格式检查通过。后续重跑编辑页 6 项也全部通过。320/390/768/1440 像素截图已检查，无横向溢出或工具栏遮挡。

当前本地旧后端仍在运行；自动重启请求被执行环境拦截，没有停止现有服务，也没有将 V049 应用到现有项目 schema。手动重启后端后由 Flyway 正常加载。未重启时编辑页显示明确提示，不伪称接口已部署。
