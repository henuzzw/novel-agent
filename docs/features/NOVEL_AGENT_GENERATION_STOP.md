# 生成任务停止

## 使用

项目顶部“生成状态”中，每个运行中的阶段显示“停止”。点击后先显示“正在停止”，后台退出并记录结果后显示“已停止”。失败会显示具体原因并允许重试，不提前伪造成功或停止状态。刷新页面后仍可按模型任务 ID 停止。

## 服务端边界

- 前端为生成 POST 附加 `X-Generation-Request-Id`，公共 Recorder 将它关联到当前模型调用。生成输入、Prompt、Schema、令牌预算和会话策略保持不变。
- `POST /api/v1/projects/{projectId}/generation-requests/{requestId}/actions/stop` 停止该 HTTP 请求当前正在执行的模型调用；`POST /api/v1/projects/{projectId}/agent-runs/{runId}/actions/stop` 停止指定模型任务。两者先校验项目归属，仅操作准确匹配的调用，不按项目批量中断。
- 返回 `STOP_REQUESTED` 仅代表已发出停止信号。原请求正常等待后台退出，不仅仅关闭浏览器连接。真正退出后 AgentRun 保存 `CANCELLED`、错误分类、部分响应和已收到的用量，不纳入失败任务统计。
- 停止与输出交接通过同一锁确定先后：停止先到，结果不会传给输出解析或后续业务；输出先进入验证／保存，停止返回 `409 GENERATION_STOP_CONFLICT`。已经完成的产物不撤销，保存事务不中途打断。
- Codex 在等待中断后向准确 thread/turn 发送 `turn/interrupt`，会话在收到终态前禁止复用。启动 RPC 中的停止先等待取得 turn ID 再中断，以免丢失远端调用身份。协议等待仍有上限，不保证网络失联时立刻收到远端确认。
- DeepSeek 使用 JDK HTTP 请求等待，中断本地调用并丢弃迟到结果。不能据此保证供应商已经停止计算或计费，已产生的费用无法撤回。
- 原文解析／创作准备同时将业务任务标为 CANCELLED，保留之前完成的段／步骤；再次执行需显式新建任务，不自动付费重试。导入规划等多步请求在当前调用中断后退出，不继续后续模型步骤。
- 停止自动创作中的单次模型调用会沿用外层失败／恢复逻辑，外层不会继续写下一步；停止整个自动任务仍使用已有取消入口。

## 部署与限制

无新依赖、数据库迁移或付费模型验证。停止注册表仅存在于当前服务进程。多实例部署需要将停止请求路由到执行实例；升级前已在运行的请求、模型尚未开始、模型完成后的 HTTP 保存、重启遗留的 RUNNING 记录不会假装可停止，会返回明确冲突。后端需重新启动加载，请在当前创作请求结束后重启，避免打断作者正在生成的任务。

## 验证

覆盖项目隔离、请求／任务精确关联、重复停止、保存阶段冲突、迟到响应禁止处理、用量和响应保留、工作线程中断标记清理、真实本地 HTTP 等待取消、Codex 中断及会话复用保护、Graph 请求上下文、桌面／手机停止按钮和页面刷新后的模型停止。所有供应商响应均使用本地模拟，不操作真实项目内容。
