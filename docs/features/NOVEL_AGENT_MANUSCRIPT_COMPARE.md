# 正文草稿版本对比

## 入口与范围

在章节写作工作台选择“版本对比”。左侧列出当前章保存的独立版本，默认对比最新版本与它记录的基准版本；没有基准记录时选择相邻旧版。可以任意选择两个版本、交换左右、查看生成来源及修改说明。

对比正文、标题、摘要、连续性备注，支持：

- 左右对齐或合并显示，删除用红色、增加用绿色，改动处进一步高亮具体字词。
- 原始行号、差异数量、上一处／下一处跳转。
- 默认折叠远离差异的未改行，可以逐段展开或关闭“仅看差异”。
- 精确保留空格、标点及换行差异；换行格式或末尾换行不同会显示标记。
- 项目、章节、两个版本、比较字段和显示方式保存在路由，刷新及浏览器前进／后退可恢复。无效或跨章节版本 ID 不直接使用。
- 加载、失败重试、无版本、单版本及内容一致分别显示状态。

未保存的编辑不参与对比。当前普通“保存”会更新同一可编辑草稿行，并非每次保存都创建不可变快照；版本对比展示的是已有的独立版本记录。重新创作、修订及局部编辑生成的新版本可以分别比较。此功能不包含回滚、合并、自动发布或正史变更。

## 实现

前端复用 `GET /api/v1/projects/{projectId}/chapters/{chapter}/manuscripts` 的版本摘要和 `GET .../manuscripts/{id}` 的完整内容。版本所属项目、章节及 ID 再次核对后才展示；不新增后端接口、表或模型调用。

`ManuscriptHistoryPanel.vue` 负责读取历史、选择、元信息及字段切换；`TextDiffView.vue` 负责渲染和差异导航；`text-diff.ts` 使用 jsdiff 的行级比较与 Unicode 字符比较，保留原文，不用 HTML 插入正文。比较设置时间与编辑长度预算；大范围改写超过细粒度预算时退化为整行高亮，不隐藏内容。

单元验证覆盖任意版本、真实基准选择、交换、不同字段、错项目响应、中文字符、空白／换行、增删与折叠。单条浏览器流程覆盖差异导航、URL 恢复、桌面及手机布局，并确认不发起写请求。无真实模型调用。

本次仅需前端热更新或重新构建，不需要重启后端。
