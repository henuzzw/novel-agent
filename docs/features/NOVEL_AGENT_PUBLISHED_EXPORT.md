# 已完成正文一键导出

## 使用

项目网页右上角点击下载图标（悬停提示“导出已完成正文”），下载 `书名-已完成正文.md`。导入、大纲、资料、任务及其他项目标签页均可使用，离开项目后隐藏。一次导出所有符合条件的章节，不受当前选中章节影响；包含书名、卷名、章号、章节标题及完整正文，按章节号排序，连续同卷只显示一次卷名。正文段落保留，不导出摘要、记忆条目、审阅意见或提示词。

## 范围

- 只取当前有效发布提交绑定的作者已确认正文，不取最新草稿或已替换发布稿。
- 对应发布版本的记忆整理必须为 `SUCCEEDED`。`PENDING`、`RUNNING`、`NEEDS_CONFIRMATION`、`FAILED`、`SKIPPED`、缺少记忆任务均不纳入。
- “已完成审阅且加入记忆”以发布后记忆整理完成为准，不另要求作者执行手动质量检查。质量检查可跳过，不能因为跳过就漏掉已完成发布与记忆整理的有效正文。
- 可以导出部分完成的章节，编号保留真实章号，不重新编号，也不以未完成章占位。没有合格正文则页面显示原因，不下载空文件。
- 卷名从正文生成时所绑定的大纲读取，不使用最新大纲草稿。没有分卷来源标记“未分卷”；已绑定来源丢失则明确报错，不能悄悄改用新版卷名。
- 人物显示名称复用现有姓名渲染，整份导出只读取一份映射，不写回存储正文。

## 接口与验证

`GET /api/v1/projects/{projectId}/canon-commits/export` 返回UTF-8 `text/markdown` 下载附件，`Cache-Control: no-store`。先校验项目归属，再于只读REPEATABLE_READ事务中读取发布、记忆、正文和来源大纲，避免导出时新发布混入不同快照。没有数据库迁移或模型请求，不发布、不审批、不更新记忆与正史。
