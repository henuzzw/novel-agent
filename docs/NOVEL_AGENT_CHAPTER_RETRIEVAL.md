## 索引与查询

1. V058新增semantic_document_chunk，关联可重建semantic_document，不改变小说权威表。
2. 每块最多600个UTF-16字符，优先换行/句尾切分，过长连续文本有限切分；完整保存精确原文、来源文档、序号和半开字符范围。范围对应索引源全文，不是行号或模型引文编号。
3. 正史Kafka投影同步创建分块；后台逐批补齐旧索引，并从当前已发布规划快照建立PLANNING_NOTES副本。更新文档时先取消完成标记，再以短事务替换全部块；重建中的文档不召回。
4. 后台每分钟至多处理5份待分块文档、8个缺失或模型不匹配的片段向量，不在写作请求里一次嵌入全书。实际回填进度依资料量而异；索引未就绪不表示小说事实不存在。
5. 查询来自本章标题/计划与当前要求，已知人名优先进入关键词；中文使用有上限的词片段兜底，不增加查询分析模型。向量查询最多使用前2000字符，完整本章计划仍直接提供正文模型。
6. 两种排序经倒数排名融合；融合分数是排序分数，不是余弦相似度百分比或可信度。同一块只出现一次，同章不同块不合并丢失。
7. 返回实际命中块，不再固定返回章节前4000字符。标明项目、来源版本、类型与字符范围；预算内提供完整命中块，不额外截成半段。超过预算的来源在提示中注明未纳入。

## 范围限制

- 正文：同项目、有效提交、提交水位不超过本次水位、章节在目标章之前。
- 规划：本次指定版本、项目当前已发布版本，索引全文与当前保存全文一致；未确认候选和旧版本不混入。
- 向量：查询模型与索引embedding_model一致。没有向量或嵌入服务不可用时，精确关键词仍可以查已有分块。
- 规划片段标为AUTHOR_PLANNING，不写入GraphFact，不证明已发生、不证明人物知情、不允许提前兑现。
- 相似命中不证明客观事实；没有命中也不证明资料不存在。检查与修订仍只能使用所提供的可核对依据。

## 限制与部署

默认仍使用local-feature-hash-v2-1024，没有自动申请远程Embedding密钥、下载模型或切换供应商。远程OpenAI-compatible适配器保持现有1024维配置。当前语义质量不能等同于语言模型嵌入；精确关键词兜底也不保证召回所有隐含关系。

本轮不新增复杂文学结构校验、不自动读取全部相邻片段、不进行全书实体共指推断或重排模型调用。不明确的人物与关键规则直接保留，不能用检索替代。

验证采用轻量定向单元回归和独立随机PostgreSQL测试空间，覆盖真实pgvector查询、章节后半段召回、跨项目/未来章/撤回/水位过滤、规划过期、模型不匹配、嵌入失败兜底、分块幂等、预算和写作版本边界。不以模拟模型或关键词断言证明文学质量。
