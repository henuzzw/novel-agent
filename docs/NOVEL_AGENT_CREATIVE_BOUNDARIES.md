# 世界设定与改编幅度

## 选择与默认值

新建项目、导入页和项目设置提供两个独立单选组，默认均为 AUTO：

| 设置 | 可选值 | 自动判断规则 |
| --- | --- | --- |
| 世界设定 | AUTO、REALISTIC、REALISTIC_FICTION、ALTERNATE | 在已有原文解析调用中识别故事世界；没有架空或虚构制度依据时采用现实写实。 |
| 改编幅度 | AUTO、PRESERVE_CORE、RESTRUCTURE | AUTO 保留核心主线；模型不得根据“爽文”自行授予重构权限。作者明确选择 RESTRUCTURE 才授权项目级重构，仍服从 KEEP、已确认设定及续写事实。 |

世界判断不等于现实事实核查。现实校园允许虚构人物和日常情节，但不能捏造官方赛事、升学优惠或特殊资格；虚构活动模式可设计校内赛和邀请赛，必须交代组织者、条件、赛制、资源和合理奖励，不冒充真实官方制度。架空模式也须遵守已建立规则。

爽度、表达风格、世界设定和改编幅度相互独立。校园关系的强回报优先从公开维护、明确选择、信任恢复和关系主动权中产生，不默认转成“晋级—冠军”。

## 原文判断与保存

原文解析仍返回带保存标题的纯文本，不向供应商发送 JSON Schema。内部批次新增 worldAssessment，包含 worldMode、reason 和最多三条原文证据；非现实模式必须附证据。证据沿用章节 UUID、连续逐字引文及 occurrence，与普通解析项一起校验来源范围。

仅在全部分段完成且来源指纹有效后，合并分段判断并写入 novel_project.settings.creativeBoundaries。幻想世界依据优先于现实背景虚构活动；后续普通生活片段不清除前段已建立的幻想世界。比喻、梦境、电影类比和素材中的命令不应作为架空依据。语义判断仍由模型完成，不承诺绝对准确；作者可改选。

保存用户选择、模型判断、判断原因、来源导入 ID 和来源指纹。用户明确选择优先于模型判断；相同来源复用判断，新来源完成解析后更新。清除自动判断只删除项目判断快照，下次完整解析时重新判断，不立即发起付费请求，也不删除原解析报告。

未完成解析时采用现实写实与保留主线的保守默认，不伪装成已完成判断。旧项目不会被批量重解析或改写。

## 执行链路

- 系统角色保留通用业务边界；共用模型网关向每轮服务端执行规范注入具体项目选择，Codex、ChatGPT 直连、DeepSeek 一致，任务记录保存实际 Prompt。不将可变选择固定进 Codex 初始系统角色，避免复用会话时旧选择与新选择冲突。
- 雪花九步开始时把边界冻结到 snowflake_plan 输入；第七步复用的人物设计同样使用快照，全程不重新读取可变选择。
- 写作上下文将边界纳入依据指纹；自动 A/B/C 通过冻结完整依据读取边界，循环中不追加当前项目设置。设置变化后原有来源复核阻止保存失效结果。
- 设置切换只影响后续任务，不自动发布规划、不重写正文、不提交正史。已发布规划与新边界冲突时，模型须指出冲突，不能把设置切换当作改写事实授权。
- 没有新增 Agent、模型调用或在线事实核查服务。需要可靠现实规则时仍须提供来源；B/C 不得仅凭内部自洽宣称完成外部核实。

## API

`GET /api/v1/projects/{projectId}/settings/creative-boundaries` 返回用户选择、实际采用、判断状态、原因、来源 ID 和项目行版本。

`PUT` 接收 worldMode、adaptationScope、version 及可选 resetAssessment；校验项目归属、悲观锁与行版本。冲突返回 409，不覆盖作者修改。

新建项目 JSON 和 from-story multipart 均接受两个可选字段；不提供则 AUTO。存储复用已有 JSONB settings，无新增数据表或迁移。

## 验证范围

定向验证覆盖保守默认、人工优先、模型不授予重构、同来源复用、新来源更新、分段合并、逐字引文、版本冲突、网关请求、雪花冻结与前端提交。隔离数据库测试使用供应商替身，不调用真实模型；不以测试通过证明小说质量或现实赛事存在。
