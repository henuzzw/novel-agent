## 页面入口

- 新建项目及项目设置：创作策略；与全局模型和项目写作风格分开。
- 写作工作台：合同执行信息、检查与润色、前三章专项、局部改写及候选差异。
- 项目工作台“伏笔与承诺”：计划、证据状态及全书来源巡检。
- Agent 运行详情：按需查看请求快照，区分实际 Token、估算 Token 和未知 usage。
- 大纲页“分块规划”：批次创建、逐块执行、失败/取消后明确恢复、查看成功片段、拼装草稿；作者仍通过原大纲编辑和发布入口检查产物。
- 故事圣经页“人物底稿”：按人编辑身份背景、性格动力、能力/声线、开篇状态与作者侧秘密/弧线；“补全人物底稿”仅针对最新已保存版本，生成新草稿后明确发布。

## 安全和兼容边界

- 不新增框架或强制供应商依赖；沿用 Java / Vue / PostgreSQL 和现有模型接入。
- 新迁移为 V037 请求审计、V038 三章报告、V039 台账、V041 规划检查点、V042 规划批次与前置依赖；V040 未使用，版本间有空号不影响 Flyway。
- 批次只针对未建立正史且没有 OCCURRED 计划的项目，从第一章开始。每次点击至多一个模型调用，不后台无限推进。失败/取消保留成功前缀，迟到结果不能覆盖恢复状态；来源变化不能继续。新请求携带已发布圣经 ID 与行版本，避免不同圣经同一行版本误用。
- 片段的前置大纲是未来计划，不是已发生事实。拼装校验连续范围、成功状态、依赖指纹和篇幅交集，保留正文/正史及原当前大纲指针；不宣称机器已经证明跨块文学因果正确。
- checkpoint/2 将渲染后的圣经和前置结果指纹纳入依据，旧 checkpoint/1 结果需重新生成，不能静默当作新依据复用。完整前缀超出模型预算时拒绝发送，不静默压缩；分层规划摘要仍待补。
- 所有模型产物为候选。局部改写只替换授权选区、保存新草稿；作者确认和正史审稿/提交仍单独进行。
- 台账计划不等于实际发生；实际状态需作者确认和当前正文逐字证据，不自动物化成正史事实。
- 本地模板不能冒充语义检查或润色；三章缺失/未评估明确显示，局部模型改写不使用本地模板伪造候选。
- 全书巡检是 RULES_SUMMARY_ONLY：仅来源、正史摘要、规划和台账规则，不读取全书正文、不推断文学质量；未登记兑现不等于正文没有兑现。
- `--novel.writing.craft-rules-enabled=false` 仅关闭新增 WritingCraftRules 块。大纲策略、原有风格指南和其他融合功能仍生效，不是完整旧模板回滚。
- 请求审计为项目私有接口，不暴露密钥。真实费用未知时不按估算值冒充账单。Codex 复用线程历史预算未知，实际输出上限未知。
- 人物底稿使用既有 JSONB，无新 SQL 迁移或依赖；旧记录缺失字段兼容为空数组。补全事务外一次真实模型调用，保存时复核源版本、内容和姓名，仅填空白及缺失人物；非空字段和圣经其他内容由程序保留。不自动合并 character_profile、不写动态正史、不自动发布或付费重试。普通圣经输出预留增加至 10000，补全 8000；不增加常规调用但可能增加耗时与费用。
