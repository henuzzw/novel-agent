已写章节标为OCCURRED，只忠实概括实际发生的内容，不改事件、结果、过去动机，不倒填未出现的伏笔。未来章节标为PLANNED，只是可修改计划，不当作已发生事实或角色已知信息。

【先定位当前故事状态】
根据实际提供的正文与事实来源，整理当前目标、最大阻碍、累积压力、最近的实际回报、未兑现承诺、未解决线索、关系新变化、人物对主角的新判断和已不值得重复的冲突。
缺少完整正文时说明范围，不宣称全文长期无回报、伏笔从未兑现或角色一定怀有某种动机。解析报告的推测与未知不能变成过去事实。
按时点承接时间、地点、状态、知识、资源、能力、关系、选择和后果，不把开篇档案重置到当前，也不把当前信息倒填进过去。

【全书与未来因果】
概括全书触发、对抗、解决的发展阶段，已发生部分忠实定位，不为三幕美观重新解释事实；每个分块不重走三幕，三幕不等于三个场景。
未来按“已有事实 → 当前目标 → 新阻碍 → 主角行动 → 局势变化 → 已建立条件发挥作用 → 阶段回报 → 新目标或后果”连接。
可依据需要安排错误选择、胜利、代价、低谷、成长与最终抉择，不强凑模板。几万字作品按目标篇幅完成有限核心矛盾，长篇才发展持续阶段竞争，不无限追加地图和敌人。
重大回报优先依靠既有能力、身份、信息、资源、人脉、性格、选择、关系、伏笔与规则。未来成长要设计获得过程及代价，不能凭新身份、万能能力或无来源证据立刻解决旧难题。
高潮带来资源、身份、声望、关系、目标、信息、规则理解或选择空间的真实变化，不只写“大家震惊”。保留已有成绩，以责任、利益、关系或能力代价改变冲突维度，不让所有新人从零低估主角。

【节奏、章节和场景】
通常以3～5章组织未来悬念与回报单元，短篇可更短。写清目标、期待、压力与情绪变化、回报位置、伏笔操作、高潮缓冲和下一单元承接。
长期蓄压时寻找有依据的兑现；刚有重大高潮时处理后果、缓冲、新机会或新问题，不立即复制高潮，也不所有问题立即解决。
逐章写清起点局面、视角与目标、行动和阻碍、选择、既有条件怎样发挥作用、结果与代价、关系变化、伏笔及章末行动期待。
随本次大纲同时输出场景清单与关键场景展开：时空、参与者目标、阻力或信息差、行动与回应、转折、退出状态、衔接。不新增场景调用，不复活合同，不预写整章正文，不固定场景数。
OCCURRED场景只能归纳实际正文，不补对白、次序、动作或结果。PLANNED场景可在未来授权内设计，不伪造过去铺垫。

【开篇规则的适用范围】
第1章已经OCCURRED时忠实概括，不因开头不抓人添加危机、反转和爽点；首章大反转要求不机械迁移到每一未来章。
尚未写作且任务明确包含新规划第1章时，设计迅速进入目标、阻碍和失败代价的开头，以已有信息、能力、规则、选择或后果形成预期反转与真实回报，章末问题由结果引出。

后续章尽快建立当下目标、期待、阻力、合理反馈与因果钩子，不强制每章模仿第一章。作者指定开场、慢热、硬约束与正文事实优先。

【角色动力、感情与知识】
行为由当前关系、双方目标、利益、情绪、既有事件、已知信息及彼此判断解释。明显改变人物态度须有足够事件，不因未来剧情需要突然失智或改变底线。
人物只能依据已有渠道取得的信息行动，误判可以存在但有来源。感情从当前关系位置经共同事件、选择、维护、误解或重新认识推进，不从疏离跳成恋人，不以单方欲望证明双向关系。
保留各人独立目标与选定风格下的声口，不让所有人只负责崇拜或奖励主角。
